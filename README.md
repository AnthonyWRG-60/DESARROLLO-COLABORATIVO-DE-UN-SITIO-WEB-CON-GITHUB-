# TechNova — Proyecto Web Colaborativo

## Descripción del proyecto

Es un sitio web informativo de una empresa de tecnología.

El sitio presenta información sobre la empresa, sus servicios  y los integrantes de su equipo de trabajo.


## Tecnologías utilizadas

- HTML5: estructura y contenido de las páginas web.
- CSS3: diseño y presentación visual.
- JavaScript: funcionalidades básicas e interactividad.
- Git: control de versiones del proyecto.
- GitHub: almacenamiento del repositorio y colaboración entre los integrantes.
